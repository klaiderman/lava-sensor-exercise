# Custom images
Copy pageCopy page
Copy pageCopy page
Custom images allow you to use iPXE scripts to boot into your operating system of choice. Using an iPXE script to deploy a custom image gives you more flexibility and control over deployments, as you can customize an operating system to your needs and requirements. You must set a valid public URL where your iPXE script is stored. Your script should follow [iPXE standards](https://ipxe.org/scripting).
## 
[​](https://www.latitude.sh/docs/servers/custom-images#what-is-an-ipxe-script)
What is an iPXE script
The iPXE script contains a set of instructions that specify how the network boot process should be performed. This can include loading an operating system image from a remote server, setting up network configurations, and executing custom scripts or commands. [Learn more about iPXE](https://ipxe.org/)
## 
[​](https://www.latitude.sh/docs/servers/custom-images#dhcp)
DHCP
Custom images use DHCP to automatically assign an IP address during boot, so you don’t need to manually configure network settings.
## 
[​](https://www.latitude.sh/docs/servers/custom-images#how-to-deploy-a-custom-image)
How to deploy a custom image
  1. For the Operating System option on the server create page, paste your iPXE script under **Custom images** or select one of the examples from the right.

![Custom image selection on the Latitude.sh dashboard](https://mintcdn.com/latitudesh/ZWurrjun6MJRTyC0/images/product/9.Docs25Q4.CustomImages.png?fit=max&auto=format&n=ZWurrjun6MJRTyC0&q=85&s=41915dc9cb156b21e6d9e05e92706105)
  1. Finish filling out the rest of the server create form as usual, including selecting the server type, location, and any other options you need.
  2. When ready, click the **Deploy** button at the bottom of the page. Latitude.sh will begin deploying your server using your iPXE script, and you should see status updates on the server’s progress in your account dashboard.

Custom images take between 10 and 30 minutes to deploy, depending on the size of the image you are deploying.
## 
[​](https://www.latitude.sh/docs/servers/custom-images#caveats)
Caveats
When deploying with a custom image, the server will report as active and show the **On** status in the dashboard. That doesn’t mean your image has finished installing. You will need to access the server console via [Remote access](https://www.latitude.sh/docs/servers/remote-access) to follow the installation process and make prompt selections, if applicable.
## 
[​](https://www.latitude.sh/docs/servers/custom-images#alternative-deployment-methods)
Alternative deployment methods
If iPXE scripts don’t meet your needs, you can also deploy custom operating systems using IPMI virtual media. See our [Custom OS via IPMI deployment guide](https://www.latitude.sh/docs/guides/ipmi-custom-os-deployment) for detailed instructions.
