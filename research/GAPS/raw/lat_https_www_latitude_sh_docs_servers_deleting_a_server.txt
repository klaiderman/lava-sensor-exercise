# Deleting a server
Copy pageCopy page
Learn how to delete a server immediately or schedule it for deletion.
Copy pageCopy page
Deleting a server permanently erases all data on its disks and **cannot be undone**. Ensure you are deleting the correct server. Note that it may take up to an hour for the deletion to reflect on your billing summary.
## 
[​](https://www.latitude.sh/docs/servers/deleting-a-server#immediate-deletion)
Immediate deletion
Follow these steps to delete a server:
  1. Open the server’s page on the [dashboard](https://www.latitude.sh/dashboard/).
  2. Click **Actions** and select **Delete server**.
  3. Confirm the deletion by typing the server’s hostname.

![Delete server confirmation](https://mintcdn.com/latitudesh/jTa6J8Hv5F4W4vnJ/images/product/19.Docs25Q4.DeleteServer.png?fit=max&auto=format&n=jTa6J8Hv5F4W4vnJ&q=85&s=426e48b4f1545701f358b185a9c4c9ed)
## 
[​](https://www.latitude.sh/docs/servers/deleting-a-server#scheduled-deletion)
Scheduled deletion
You can schedule a server for deletion at a future date, allowing you to plan decommissioning while the server continues running. To schedule a deletion:
  1. Open the server’s page on the [dashboard](https://www.latitude.sh/dashboard/).
  2. Click **Actions** and select **Schedule deletion**.
  3. Choose the date and time for the deletion.
  4. Confirm by typing the server’s hostname.

When a server is scheduled for deletion, an alert banner appears on the server details page showing the scheduled date.
## 
[​](https://www.latitude.sh/docs/servers/deleting-a-server#canceling-a-scheduled-deletion)
Canceling a scheduled deletion
You can cancel a scheduled deletion before it occurs.
  1. Open the server’s page on the [dashboard](https://www.latitude.sh/dashboard/).
  2. Find the alert banner indicating the scheduled deletion.
  3. Click **Cancel** on the alert banner.

The server will continue running normally.
